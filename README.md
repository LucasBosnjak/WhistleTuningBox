The code itself works well, but Arduino Uno has such low ram(2kbits), that an accurate FFT calculation is very challenging to perform.
This causes wrong notes to sometimes appear. Moreover, I used a very cheap analog microphone module which is not very accurate, and causes further misses in pitch capturing.

Project was started on 19.10.2026 and completed on 21.10.2026

Components: Arduino UNO, Analog microphone, passive Piezo Buzzer, 3 buttons(clear memory, record and play).
